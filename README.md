# RaceDelta

> A MoonBit race strategy analyzer and counterfactual simulator.

**Status: MVP complete / early development.** RaceDelta is an offline teaching tool for turning lap-by-lap CSV data into a deterministic race timeline, replaying one explicit alternative pit strategy, and explaining the resulting crossover points in Markdown. It does not claim to predict real races precisely.

## Requirements

- A MoonBit toolchain with the Native target. This repository was verified with MoonBit `0.1.20260920` on Windows.
- The declared `moonbitlang/async@0.20.2` dependency is already recorded in `moon.mod`. Normal `moon check`, `moon test`, `moon build`, or `moon run` synchronizes declared dependencies when needed; users normally do **not** need to run `moon add` themselves.

## From input to explanation

```text
CSV v1 -> validated timeline -> explicit counterfactual pit plan -> crossover explanation -> Markdown report
```

RaceDelta validates the CSV, reconstructs cumulative times, positions, gaps, stints, and events, then replays the selected target driver's replacement pit plan against an unchanged opponent. The report distinguishes performance, strategic, and opponent crossovers instead of only returning a final time delta.

## Quick start

From the repository root:

```sh
moon check --target native
moon test --target native
moon run cmd/main -- examples/basic_race.csv --driver ALP --opponent BRV --stops 2:MEDIUM
```

The last command writes a Markdown report to stdout. To create or replace a UTF-8 file, append `-o report.md`.

`--stops` accepts:

```text
none
2:MEDIUM
1:HARD,2:MEDIUM
```

These respectively mean no planned stop, one planned stop, and multiple planned stops. A stop happens at the end of the listed lap and the new compound starts on the following lap. See [CLI.md](CLI.md) for the complete syntax, validation rules, Windows-path examples, and exit behavior.

## Examples and reproducibility

- Input: [basic_race.csv](examples/basic_race.csv) and [mixed_conditions.csv](examples/mixed_conditions.csv)
- Generated report: [basic_strategy_report.md](examples/basic_strategy_report.md)

The checked-in report is generated by the project CLI with:

```sh
moon run cmd/main -- examples/basic_race.csv --driver ALP --opponent BRV --stops 2:MEDIUM -o examples/basic_strategy_report.md
```

The repository currently has **209 automated tests**. Run them with `moon test --target native`.

## Limits

- Pace and pit-loss parameters are illustrative teaching assumptions, not official F1 data for a circuit, tyre, team, or driver.
- RaceDelta does not recreate a team's internal model, model full traffic/DRS/overtaking/driver AI, or search strategies automatically.
- Safety Car laps preserve the supplied input timing; RaceDelta does not compress real input gaps.
- On an async-main failure, the official Native runtime may also emit a short `Failure(...)` diagnostic to stdout. RaceDelta writes its human-readable error to stderr and does not use private exit APIs, FFI, or wrapper scripts to suppress that runtime behavior.
